# WP-050 — Primeiro domínio novo

**Estado:** PLANNED  
**Tipo:** implementação futura

## Resultado esperado

Um novo bot ou domínio, escolhido pelo usuário, criado somente após fundação de memória, matriz de permissões e testes de isolamento.

## Fora de escopo

Escolher implicitamente o domínio, reutilizar credenciais pessoais ou expandir o default.

## Pré-requisitos

WP-010, WP-020 e WP-040 verificados; WP-030 se o domínio requer conhecimento 24/7 na VPS.

## Gate

O usuário escolhe entre compartilhado read-only, família, finanças, viagens, radioamadorismo ou infraestrutura. A escolha abre um WP específico e um change set próprio.
